# Origem e licença do corpus

Os arquivos Markdown deste diretório foram obtidos de [ctresb/leis](https://github.com/ctresb/leis), no commit registrado em `index.json`.

Conforme a documentação do projeto de origem, os textos das normas são atos oficiais do poder público e, pelo art. 8º, I, da Lei nº 9.610/98, não são objeto de proteção autoral. Os scripts do projeto de origem são licenciados sob MIT por João Davi (2026); nenhum script de coleta foi copiado para este projeto.

Cada documento preserva o cabeçalho e a fonte oficial quando disponibilizada pelo acervo. A Constituição mantém a nota de origem do Planalto. A sincronização opcional usa a API pública do GitHub e não contorna bloqueios de acesso.

## Aviso jurídico

Este corpus é um recorte pequeno do acervo, destinado a pesquisa informativa. Pode conter conversões automáticas, OCR, lacunas ou atualizações posteriores. Não substitui o Diário Oficial, a consulta à fonte indicada nem orientação jurídica profissional. Antes de citar ou tomar decisões, confirme o texto e sua vigência na fonte oficial.
