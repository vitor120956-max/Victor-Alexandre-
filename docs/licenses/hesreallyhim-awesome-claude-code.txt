O QUE FOI USADO
---------------
Apenas o MECANISMO descrito publicamente no repositório: o schema de 12 colunas,
as regras de elegibilidade (14 dias de desenvolvimento ativo ou 100 estrelas),
o formato do formulário de recomendação, o uso de ID opaco como chave, a geração
do README a partir de uma tabela CSV, a comparação de snapshots de estrelas e a
auditoria de higiene de uma lista.
